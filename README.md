- React.js
- Vite
- Tailwind CSS
- React Icons

## Installation

Clone the repository

git clone https://github.com/anuj9571/Northpeak-Digital.git
Go to project folder

cd Northpeak-Digital
Install dependencies

npm install
Run development server

npm run dev
Build project

npm run build
